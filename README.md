# Scholarship AI Matcher

A Python + Streamlit web application that helps students find scholarships based on GPA, major, state, first-generation status, and financial need.

## Features
- Rule-based scholarship matching
- Match score ranking
- Streamlit frontend
- CSV scholarship database
- Future AI embedding integration

## Tech Stack
- Python
- Pandas
- Streamlit

## Future Improvements
- AI semantic matching with embeddings
- Expanded scholarship database
- User accounts
